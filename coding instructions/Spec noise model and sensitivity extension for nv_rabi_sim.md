# Spec: noise model and sensitivity extension for nv\_rabi\_sim

Nov 11, 2026 · @hills

## Goal and scope

Extend the existing `nv_rabi_sim` project (files: `config.json`, `physics.py`, `plotting.py`, `main.py`) with four things: coloured noise generated by IFFT of a user-specified PSD, pulse-length jitter, thermal and vibration noise sources, and a square-root PSD (amplitude spectral density) plot that estimates ultimate sensitivity in T/√Hz.

**Unchanged:** the existing model (two-level, rotating-wave approximation, static ensemble spread from T₂\*, ¹⁴N hyperfine lines, amplitude spread, Poisson shot noise), the physics/plotting split, and all existing config keys. With every new noise source and jitter switched off, outputs must match the current version.

**Conventions:** time in µs, ordinary frequency in MHz, pulse length in ns, acquisition time in s, magnetic field in T. The electron gyromagnetic ratio is γₑ = 28 GHz/T (28 000 MHz/T), used only to convert detuning to field.

**New files and changes:**

| File | Change |
| --- | --- |
| `noise.py` (new) | Pure numerics, no matplotlib: PSD model, IFFT noise generator, Welch PSD estimate |
| `physics.py` | Jittered ensemble population, per-point parameter noise, linear-response slopes, working-point search |
| `plotting.py` | Three new figures and an updated `rabi.png` |
| `main.py` | Orchestration of the new paths, new `summary.json` fields |
| `config.json` | New blocks listed in the next section |

## Coloured noise generator (`noise.py`)

Each noise source is a zero-mean Gaussian time series with a one-sided PSD, defined from the config as:

```latex
S(f) = A_{ref}^2 \left(\frac{f}{f_{ref}}\right)^{-\beta}
```

Here A\_ref is `asd_at_ref` (units per √Hz) and β is `slope`. The generator takes the sample interval dt as an argument and the Nyquist frequency is 1/(2·dt). Path A uses one sample per sweep point (dt as defined in the config section); Path B uses \`sensitivity.dt\_s\`.

**Functions to implement**

| Function | Behaviour |
| --- | --- |
| `psd_model(f, asd_at_ref, slope, f_ref)` | Returns S(f) as above, for f > 0. |
| `generate_noise(n, dt, asd_at_ref, slope, f_ref, rng)` | Returns a real series of length n, generated by IFFT of the PSD. |
| `welch_asd(x, dt, nperseg)` | Returns frequencies and the one-sided amplitude spectral density √S(f), using `scipy.signal.welch`. For a 2-D input (realisations × samples), average the PSD across realisations before taking the square root. |

**Generation algorithm for `generate_noise`**

1. Frequencies `f_k = rfftfreq(n, dt)`; set the DC bin (k = 0) to zero.
2. For k ≥ 1, draw a complex Gaussian `g_k = (a + i·b)/√2` with a, b standard normal.
3. Set `X_k = sqrt(S(f_k) · n / (2·dt)) · g_k`. The Nyquist bin (n even) must be real, so use a single real standard-normal draw there with the same amplitude factor.
4. Return `x = irfft(X, n)`.

The normalisation follows from the one-sided estimate S\_k = 2·dt·|X\_k|²/n. With it, a Welch estimate of the generated series must reproduce S(f) in expectation.

**Notes for the implementer**

- Noise below 1/(n·dt) is not represented, because the DC bin is dropped. State this in a docstring.
- Use one independent generator per source and per realisation, created with `np.random.SeedSequence(seed).spawn(...)`, so changing one source does not change the others.
- `slope = 0` must give white noise with PSD A\_ref² at all frequencies.

## Pulse-length jitter (`physics.py`)

Jitter is shot-to-shot: every repeat has a slightly different pulse length, so the averaged signal at each sweep point is the Rabi curve convolved with a Gaussian along τ. It is not extra random scatter, so it is computed as an expectation rather than by drawing random τ values.

**Model**

```latex
\bar{P}(\tau) = \int P(\tau') \, \mathcal{N}(\tau';\, \tau, \sigma_\tau^2) \, d\tau'
```

**Method: Gauss-Hermite quadrature**

1. Get nodes `x_i` and weights `w_i` from `numpy.polynomial.hermite.hermgauss(n_quadrature)`.
2. For each node, evaluate the existing ensemble population on the shifted grid `τ_i = τ + √2 · σ_τ · x_i`, clipping τ\_i at 0 (a pulse length cannot be negative).
3. Return `Σ w_i · P(τ_i) / √π`.

Reuse the existing `ensemble_population`; add a wrapper, for example `ensemble_population_jittered(...)`. Cost scales with `n_quadrature`, which is why it is configurable.

**Optional quantisation**

If `jitter.quantise_ns > 0`, round each τ to the nearest multiple of that value before applying jitter. This models sequencer resolution (the Arduino sequencer in the earlier literature search had 62.5 ns steps). It is deterministic and independent of the random jitter.

**Expected behaviour (for checking)**

- The rotation angle error from jitter is about 2π · Ω/2π · σ\_τ. With Ω/2π = 5 MHz and σ\_τ = 1 ns this is roughly 0.03 rad, so the effect is small. It grows with Ω and with τ.

## Thermal and vibration noise

Both are extra sources feeding the existing channels (baseline, Ω, detuning). They reuse the PSD generator and add one conversion each.

**Generator addition (`noise.py`).** Add `generate_noise_from_psd(n, dt, psd_fn, rng)`, where `psd_fn(f)` returns the one-sided PSD for positive frequencies. It follows the same algorithm as `generate_noise`, which becomes a thin wrapper passing the power-law PSD. Vibration needs this because resonance peaks are not power laws.

### Thermal

Generate one temperature series δT\_k (K) from the power-law PSD in `thermal.temperature`. The same series feeds both channels below, so the two effects are correlated. Do not draw independent series for them.

```latex
\delta_{T,k} = \left(c_D + \gamma_e B_{bias}\, c_M\right)\delta T_k \ \ [\text{MHz}], \qquad \epsilon_{\Omega,T,k} = c_G\,\delta T_k
```

Here c\_D is `diamond_d_mhz_per_k`, c\_M is `magnet_tempco_per_k`, c\_G is `mw_gain_tempco_per_k`, B\_bias is `bias_field_mt` converted to T, and γₑ = 28000 MHz/T. δ\_T,k adds to the detuning channel and ε\_Ω,T,k adds to the Ω channel.

**Microwave heating (Path A only).** If enabled, add a deterministic temperature drift to δT\_k that rises towards its final value with a first-order time constant:

```latex
T_{heat}(t) = \Delta T_{final}\left(1 - e^{-t/\tau_{th}}\right), \qquad t = k \cdot dt
```

This reproduces the slow baseline and frequency drift seen over long pulse sweeps. Path B assumes a stationary process, so heating is not applied there.

### Vibration

Displacement x\_k (m) of the magnet relative to the diamond, with a one-sided PSD built from a power-law floor plus one second-order resonance per entry:

```latex
S_x(f) = S_{floor}(f) + \sum_j \frac{a_j^2}{Q_j^2}\;\frac{1}{\left(1-(f/f_j)^2\right)^2 + \left(f/(Q_j f_j)\right)^2}
```

The peak value of each term is a\_j² at f = f\_j, where a\_j is `asd_peak_m`. The detuning channel receives:

```latex
\delta_{vib,k} = \gamma_e\, g\, x_k \ \ [\text{MHz}]
```

Here g is `bias_gradient_t_per_m`. Vibration acts only on detuning in this iteration.

**Path A (Rabi sweep).** The sweep point time (0.1 s with the defaults) is much longer than the vibration periods, so vibration above the Path A Nyquist frequency f\_N averages inside each point. Model it as extra Gaussian detuning spread, with variance from integrating the detuning PSD:

```latex
\sigma_{vib}^2 = \int_{f_N}^{f_{hi}} (\gamma_e g)^2\, S_x(f)\, df, \qquad f_{hi} = \frac{1}{2\,\text{sequence\_length\_us}\times 10^{-6}}
```

Integrate numerically on a logarithmic frequency grid. Add it in quadrature to the T₂\* spread in `sample_ensemble`: σ\_total = √(σ\_T2\*² + σ\_vib²). This is valid because the ensemble mean over spins and over shots is the average over the joint distribution, and independent Gaussian detuning spreads combine in variance. Vibration below f\_N goes in as a time series like the other sources.

**Path B (sensitivity).** Generate x\_k directly at `sensitivity.dt_s`. Resonances with f0 above the Path B Nyquist frequency cannot be represented: print a warning listing them and leave them out.

## Applying the noise, and the sensitivity path

There are two separate computations. Do not merge them.

### Path A: noisy Rabi sweep (full nonlinear model)

Used for `rabi.png` and the fit statistics. The sweep has `drive.n_points` points taken in sequence at times `t_k = k · dt`. Generate one noise series per enabled source (length `n_points`, interval `dt`) and apply per point k:

- `omega`: Ω\_k = Ω · (1 + ε\_Ω,k), applied to all spins at that point.
- `detuning`: the microwave detuning becomes `mw_detuning_mhz + δ_k` (MHz).
- `baseline`: fluorescence multiplied by `(1 + ε_base,k)`, applied after the contrast calculation and before Poisson noise.

This needs the population function to accept per-point Ω and detuning (broadcast shape spins × points). Then add Poisson shot noise as today. Repeat for `sensitivity.n_realisations` realisations and report the mean and standard deviation of the fitted Rabi frequency and decay time in `summary.json`.

### Path B: sensitivity (small-signal linear response)

A long time series is needed for a PSD (`n_samples`, for example 16384), which is too heavy for the full per-point ensemble calculation. Use linear response around a fixed working point instead.

Path B samples at its own interval `sensitivity.dt_s` (default 1 ms), independent of the Rabi sweep point time. This sets the Nyquist frequency 1/(2·dt\_s) = 500 Hz by default, which is needed to resolve vibration peaks. Photons per sample scale with dt\_s (formula below), so the shot-noise floor in T/√Hz does not depend on the choice.

**Working point.** A fixed pulse length τ₀ and microwave detuning Δ₀ at which the fluorescence y is read out repeatedly. On resonance the slope with respect to detuning is zero, so the working point must be off resonance.

- `mode: auto`: on a grid of τ (0 to `tau_max_ns`) and Δ (`detuning_range_mhz`), compute the ensemble fluorescence y with `n_spins_slope` spins and choose the point maximising |∂y/∂Δ|.
- `mode: manual`: use the configured values.

**Slopes** (central finite differences at the working point, same ensemble draw):

- `∂y/∂Δ` in 1/MHz, `∂y/∂Ω` in 1/MHz (Ω in MHz).

**Time series.** For each realisation and each sample k:

```latex
y_k = y_0\,(1+\epsilon_{base,k}) + \frac{\partial y}{\partial \Omega}\,\Omega\,\epsilon_{\Omega,k} + \frac{\partial y}{\partial \Delta}\,\delta_k + n_{shot,k}
```

Here `n_shot,k` is Gaussian with variance `y_0 / N_counts`, a Gaussian approximation of the Poisson noise in normalised units. Disabled sources contribute zero.

`ε_base,k`, `ε_Ω,k` and `δ_k` in the equation are each the sum of every enabled source mapped to that channel. The detuning channel `δ_k` is the coloured `detuning` source plus the thermal term δ\_T,k plus the vibration term δ\_vib,k. The Ω channel is the coloured `omega` source plus the thermal term ε\_Ω,T,k. The thermal terms come from one shared temperature series, as specified in the thermal and vibration section.

**Conversion to field units.**

```latex
\frac{\partial y}{\partial B} = \frac{\partial y}{\partial \Delta}\,\gamma_e, \qquad \gamma_e = 28000\ \text{MHz/T}, \qquad \eta(f) = \frac{\sqrt{S_y(f)}}{\left|\partial y/\partial B\right|}\ \ [\text{T}/\sqrt{\text{Hz}}]
```

**Shot-noise floor** (the ultimate white limit for this working point and photon budget):

```latex
\eta_{shot} = \frac{\sqrt{2\,dt\,y_0/N_{counts}}}{\left|\partial y/\partial B\right|}, \qquad N_{counts} = \text{photons\_per\_shot} \times \frac{dt_s}{\text{sequence\_length\_us}\times 10^{-6}}, \qquad dt = dt_s
```

Compute `S_y(f)` with `welch_asd` over all realisations. Also compute each source's contribution separately (same series, one source at a time) so the plot can show them.

## Acceptance checks and constraints

**Checks the implementation must pass** (put them in a small `checks.py` that exits non-zero on failure):

1. **Regression:** with all `noise.*.enabled` and `jitter.enabled` false, `summary.json` fit values and the `rabi.png` data match the current version for the same seed.
2. **Generator slope:** for `slope` = 0, 1 and 2, the Welch ASD of a long generated series (for example n = 2¹⁸) has a log-log fitted slope of −β/2 within ±0.1 over the middle decade of frequencies.
3. **Generator level:** the ASD at `f_ref_hz` is within 10% of `asd_at_ref` after averaging at least 20 realisations.
4. **Jitter limit:** with `sigma_ns` very small (for example 1e-6), the jittered curve equals the unjittered curve to numerical precision. With larger σ the oscillation amplitude must not increase at any τ.
5. **Shot-noise floor:** with all coloured noise off, the simulated ASD is flat and within 10% of `eta_shot` (converted back to fractional units).
6. **Working point:** in `auto` mode, `|∂y/∂Δ|` at the chosen point is not smaller than at any other grid point, and is non-zero.

**Additional checks for thermal and vibration noise:**

- **Vibration peak:** with only a vibration resonance enabled, the Path B ASD shows a peak at `f0_hz` whose height matches `asd_peak_m × γₑ × bias_gradient_t_per_m` (converted to the plotted units) within 20%. Use a resonance well below the Nyquist frequency and a `welch_nperseg` fine enough to resolve it (frequency resolution below f0/Q).
- **Thermal conversion:** with only `thermal` enabled and `magnet_tempco_per_k` and `mw_gain_tempco_per_k` both 0, the detuning series has an ASD at `f_ref_hz` equal to `|diamond_d_mhz_per_k| × asd_at_ref_k` within 10%.
- **Shared temperature:** enabling thermal drift with both detuning and gain coefficients non-zero gives detuning and Ω noise series with correlation coefficient of magnitude 1 (the same δT\_k scaled).
- **Heating:** with `mw_heating` enabled and all other sources off, the fitted Rabi frequency in Path A drifts monotonically across the sweep, with a time constant matching `time_constant_s`.
- **Sub-Nyquist vibration:** in Path A the added σ\_vib is zero when all resonances lie below f\_N and grows with `asd_peak_m` when one lies above.

**Constraints**

- Keep the physics/plotting split: `physics.py` and `noise.py` must not import matplotlib.
- No new dependencies beyond numpy, scipy and matplotlib.
- Every new parameter lives in `config.json`; none are hard-coded.
- Seeds come from `run.seed`; results are reproducible for a given config.
- Document units in each function docstring.

**Known limits to state in the docstrings, not fix**

- The working-point analysis uses fixed-τ, fixed-detuning readout (similar to pulsed ODMR at one frequency). It is not a Ramsey or echo sensitivity, and it does not include the overhead of choosing τ for those protocols.
- Linear response is valid only for noise small compared with the linewidth in detuning and with the contrast in fluorescence.
- Noise sources are independent Gaussian. Correlation between laser, microwave and bias noise is not modelled.

**Out of scope for this iteration:** Allan deviation plots, T₁ or Markovian dephasing, sub-pulse phase noise, and optical-pumping dynamics.
